# 给 ADR / 规格加「文首注」订正失实句，只在注与失实句同处一节时有效

## 撞出来的场景

一批 ADR 与定稿规格里留着过时句子。最省事的处方是「在文首加一条注，说明以下某处已不成立」——
不动正文、不换对内容敏感的东西，看起来风险最小。

审查者在一份 ADR 的 `## Consequences` 上吐了 ⚠️：那一节的维度声称已失实，
**且它裸奔进非首节切片，文首注按机制到不了那一节**。返工把那处**改文**。

## 现象

- 文首注写在 H1 之后、首个 `##` 之前 ⇒ 它自己是**另一个节**。
- 失实句只要**它所在的节被召回**，**整节**的正文一起进 prompt；注不在那一节里 ⇒
  两者**永不同框**。
- 结论：注式订正「诚实但不可达」——注写得再准，读的人（这里是猫的 system prompt）
  也看不到它。**注入面按节装配**：命中的是**片**，注入的是**节**。

## 机制

检索命中粒度是**片**（切片层产出的段），但注入单位是**节**：同 `doc_path + section_anchor`
的片被取回后合并，整节渲染进 prompt。

⇒ 判据不是「有没有文首注」，是**「失实句所在节」与「注所在节」是不是同一节**。

**推论（容易漏的一条）**：注写在某个 `##` 节里、订正另一个 `##` 节，**同判失效**——
「注的物理归属由节定义」，不是由文件定义。所以判据**不能**写成「非 H1 节就有效」这种窄表述。

两个装配面要分清，别混：**嵌入文本** = 面包屑 + 话题锚 + 正文，其中面包屑由
「相对路径 > H1 > H2 > H3」生成——这是**片**的装配，决定**检索能不能命中**；
**注 prompt 的装配**按节做，决定**订正够不够得着**。

## 正解

- **失实句与注不同节 ⇒ 直接改文**，不要加注。
- 引用他人失实句时把**整节**一起改，不留「已删 / 已改」单字口径。

## 可复用的动作

1. 决定「加注」还是「改文」之前，先定位**失实句在哪一节**、**注会在哪一节**；
   不同节就改文，这一步只需看标题层级，比想象中快。
2. 同判失效的边界要写清：**注写在 `##` 节里、订正另一个 `##` 节，也算跨节**。
3. **改文后回头检查注本身还成不成立**——把「以下三处与正文不同」这类指涉句留给一条已改的
   正文，注自己会变成新的失实句。
4. **「有失实」与「有危害」之间还差「是否被消费」**：本例那几份文档在记忆通电前**零切片**，
   那批失实句**从未进过检索面**。判处置力度前先取这一格读数——它可能把「紧急」降成「顺手」。
