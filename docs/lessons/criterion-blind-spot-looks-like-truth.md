# 判据的排除分支若与「本就无可指」同形，全绿不构成证据

## 撞出来的场景

扫源码注释面（`packages/**` + `scripts/**`）残留的「路径:行号」锚，判据 = 锚里的路径能否按后缀
匹配到 `git ls-files` 里的真文件。全量实测 **77 条**——而上一轮回执报的是 **2 处**，量级差约 38 倍。

## 四处「判据的排除项排掉了它该抓的东西」

1. **字符类盲区**：探针的锚基名字符类不含**内嵌点号** ⇒ `socketio.test.ts` 被拆成 `test.ts`
   ⇒ 后缀匹配不到真文件 ⇒ 在 `continue` 处**静默丢弃**。放宽字符类后基线树新增暴露 2 条。
   **被静默丢弃的正是含点号的文件名（`*.test.ts`）。**
2. **「目标须是真文件」这道门，结构上排除「目标已删 / 已迁走」这一档** ⇒ 该档结论「0 处」
   **按判据诚实、但等于没判**（构造上不可达）。修法：另走**第二道门**（该路径是否出现在
   `git log --all --diff-filter=RD --name-status` 的删除记录或 rename 旧路径里）。
3. **目标行为空白时被渲染成空串**，与「无内容可看」同形（基线树 5 条）。改为显式标注。
4. **rename 盲区**：第二道门原用 `--name-only`，而它对 rename 行**只给新路径** ⇒ 旧路径
   既不在 `ls-files` 里、也不在删除记录里 ⇒ 落「面外」静默丢弃。实测 **82 条 rename 旧路径
   与 229 条删除记录零重叠**。修法：改 `--diff-filter=RD --name-status`，R 行的**旧路径列**单收。

**四处同型，修 4、余 0。**

## 反方向的一条（判据不是一边倒）

同批里也有**实测命中**的真锚（弱符号名恰好没漂）。⇒ 结论不是「行号锚全错」，是**大概率错**
（与上一轮 67% 同量级），故口径仍是**统一去行号化、不留例外**。
真失效的 9 条里还有更重的一类：**连文件名都错**（引的那个文件里根本没有那个函数）——
**只删行号会留下仍错的锚，必须连文件名一起改。**

## 同族三形态（同一机制：判据读数的面 ≠ 它要判的面）

- **阈值分不出档 ⇒ 恒真门**：一条前端性能验收的主判据是「无 `>50ms` 长任务」，而在被测区间上
  pre / post 两版读数几乎不可分（一版三次里只 1 次跨过）⇒ 该阈值**判不出优劣**。
  正解：**主判换成能分档的指标**（帧间隔 p95），`>50ms` **降为并列证据**，
  **原阈值保留不改、不偷换**。配套**自证灵敏度**：同页每轮主动阻塞 5×120ms，
  观察者 5/5 全捕获 ⇒「0 长任务」是显性证伪，不是聋子听诊。
- **断言面把注释也算进去 ⇒ 假红**：本仓用 `?raw` 读 SFC 源文本做静态断言，拿到的是**含注释的
  整份源码**（还常按正则截规则体，注释同样在截取范围内）⇒ **注释里的旧值字面量会被断言当成
  声明本身读到**：写进否定断言即**假红**，写进正向断言即**假绿**。
  正解：**注释只写结论与理由，不写旧值字面量**。本仓已复发两次。
- **验证面绕过早退 ⇒ 假绿**：被测逻辑外面包着会**提前返回**的编排层时，整条 e2e 可能在
  「没走到被判逻辑」的情况下变绿。正解：判据**直调承重函数**，让判据的运行路径 =
  被判对象的运行路径（仓内实例：e2e 直调投递判据函数，绕开编排层的早退）。

## 通则

**判据的排除分支必须与「无对象」可区分地分开。** 凡判据把「它该抓的那一档」和「本来就无可指」
编码成**同一个出口值**（静默 `continue` / 落面外 / 空串 / 分不开档 / 早退仍绿），该出口的
**绿不构成证据**。判据须满足两条：①**结构上可达**它声称覆盖的每一档（每档都有一条能红的路径）；
②读数在「有对象」与「无对象」两种世界下**取值不同**。

反绿门的通用形态另见
[新写的验收用例必须在旧实现下必红](red-test-must-fail-under-old-implementation.md)——
那张讲的是**用例判别力**，本卡讲的是**扫描/探测类判据的覆盖面**，两者互补不重复。

## 可复用的动作

1. **给判据的每一档找一条能红的路径**；找不到的那一档，判据「诚实但不可达」= 没判。
2. **补上第二道门后，要对它再走一遍「盲区扫描」**——本例补的第二道门自己就带第 4 条那个盲区。
3. **探针宽度必须匹配判据宽度**：探针的漏抓与真值同形（都表现为「不报」），
   全绿读数不等于面已清干净。
4. **计数是探针口径的产物**：口径一改必须重取，不得沿用旧数。
5. **别用「符号名 ± N 行窗口」这类自动判活**：弱符号名假阳、符号名写在上一行时假阴——
   **双向误报 ⇒ 不可采信**；脚本的职责是把「锚 + 目标行原文」摆到一起，判定由人读原文做。
6. **引用他人产物时别用单字口径**：把「已删 / 已改」这类单字口径搬进新文档，会把它携带的信息
   削掉——被 rename 的路径要报「**已迁往某处、而该处也已删**」，而不是一个字「删」。
