# 写「唯一」「不存在」这类全域断言，必须把判据口径一起写出来——口径不同，重复组数从 3 到 2 到 1

## 撞出来的场景

2026-09-14 前后，混合检索票（每查询池化 + RRF 融合排序）要论证一件事：
**「两条不同的检索结果算出完全相同分数」这个分支到底可不可达**。

初稿写的是「四元多重集里**唯一**一组构型同分」——这是一句**全域断言**（断言了整个值域里
只有一组）。第二轮审查把它证伪：这句话是假命题，只在某个**复合口径**下才真。

## 现象

同一句话「唯一一组」，换三种口径给三个不同的数：

| 口径                                           | 同分且最优下标不同的构型数 |
| ---------------------------------------------- | -------------------------- |
| 分数按**有理数**精确相等                       | **3** 组                   |
| 再加一层「float64 累加后**逐位**相等」         | **2** 组                   |
| 再把口径限定为「**本夹具的累加顺序** + `===`」 | **1** 组                   |

三组分别是 `{2,2,2,16}`/`{5,5,5,5}`、`{2,2,2,17}`/`{4,4,4,9}`、`{2,2,19,19}`/`{9,9,9,11}`
（穷举值域 0..19，共 8855 个四元多重集）。其中第二组在「有理等值」下成立，
但试遍 4!×4! 种排列**无一命中**逐位相等 —— 舍入分歧。

**口径不写，断言就是假的**：读者按自己默认的口径去验，会得到与作者不同的结论，
而双方都不算错。

## 机制

「唯一」「只有一处」「不存在」是**全域量化**（对所有输入成立）。全域断言的真值
**依赖于等价关系的定义**——「相等」是精确还是近似？在什么累加顺序下？比的是字段还是整对象？

作者脑子里的口径是隐含的，读者默认的口径是自己的，两者不同则断言的真值不同。
所以这类断言的完整形态必须自带口径：**「在口径 C 下，唯一」**。

## 可复用的动作

凡要写「唯一」「不存在」「只有一处」：

1. **先钉死谓词**：写清楚「相等」的判据是什么（`===`？容差多少？哪个累加顺序？
   比哪几个字段？）。钉不出谓词 ⇒ 这条断言还没法证。
2. **把口径写进同一句话里**，不要另起一句当补充说明。
3. **口径本身要有反向对照**：换个口径读数**必须变**（3 → 2 → 1 就是这个对照本身）。
   换个口径读数不变 ⇒ 说明这个口径没在起作用，你测的是别的东西。
4. **穷举域要写出来**：`8855 个四元多重集`（值域 0..19）与「唯一」是同一句话的两半，
   缺了前半句，后半句无法复算。

## 同族

与「**不存在 X，必须先钉死 X 的谓词再证**」是同一条。
也与本仓另一条通用判据同源：**验证面必须与被判面同面**——
你声明的口径（被判面）和你实际测的口径（验证面）不同时，结论无效。
