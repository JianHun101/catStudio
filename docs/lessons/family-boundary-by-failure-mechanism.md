# 「整族修」的族边界按失效机制划，不按上次 grep 的那个模式划

## 撞出来的场景

一张票要修「env 阈值解析成 `NaN` 后静默穿透」这一族。票面自己定的扫法写在正文里：
「本次搜的是 `parseFloat`」。

派活前实核族边界，**少了 `parseInt` 侧的两处**——`git grep "parseInt(process.env"` 天然不在
`parseFloat` 的模式面上。漏掉的两处恰是**全族危害最重的**：

- `MEMORY_TOP_K`：`parseInt` ⇒ `NaN` ⇒ 末次 `.slice(0, NaN)` 得空数组 ⇒ **注入 0 片**；
- `MEMORY_MAX_DISTANCE`：`NaN` 进 SQL 绑定与比较 ⇒ **检索面静默改变**。

前五处失效的是「告警 / 徽章 / 交接触发」这类**可见性**面；这两处失效的是**检索本身**——
猫再也检索不到记忆，而日志一片安静。

票面自己的结论：这不是手滑，是**定族方法**缺陷。

## 现象

- 族边界定错 ⇒ 同因站点留在族外 ⇒ 产出「**整族已清**」的**假读数**。而这类票的靶心恰恰
  就是消灭静默通过——门禁自己变成静默放行的一种。
- 危害排序会反：模式扫出来的是最显眼的那个模式，漏掉的往往是另一模式下的**热路径**。
- 后续验证再严也补不回来：验证面继承的是错误的族边界。

## 机制

族的定义是「**同一失效机制**」，不是「上次 grep 用的那个字面」。

本例的机制一句话：**裸 parse 无有限数守卫 ⇒ `NaN` 穿透 ⇒ 下游静默失效**。
同一机制在四个消费形态上现形：

- `<` / `>=` 比较**恒为 `false`** ⇒ 阈值形同被禁用，且**无任何日志**；
- `parseInt` → `NaN` → `.slice(0, NaN)` ⇒ 空数组；
- `NaN` 绑进 SQL ⇒ 检索面静默改变；
- `listen(NaN)` ⇒ 抛 `ERR_SOCKET_BAD_PORT`（**全族唯一的 fail-loud 反例**）。

熔断点还选错了层：`env.ts` 用 `??=` 兜默认值——`??=` 只兜「**未设置**」，
不兜「设成非数字」。修法因此**不放 `env.ts`**（不做「在入口统一加校验一杀」），
而放**消费点就近回退各自默认值**。

## 正解

- **回退默认值，不回退 0**：`slowMs=0` 会把每一跳都标 slow，是**另一种假数**。
- **回退时打一条 warn**（含变量名 + 原始串 + 回退值）——「『静默』本身就是这个 bug 的一半，
  修了值却不留痕等于只修一半」。
- **逐键裁 fail-loud vs fail-safe，不机械并轨**：`PORT=abc` 现行行为是 `listen(NaN)` 抛
  `ERR_SOCKET_BAD_PORT`（fail-loud），并轨到统一入口会把它**降级**成 warn + 回落默认端口。
  先实测该键坏值下的现行行为，再按键给结论。

## 可复用的动作

1. **写族边界前先写「失效机制」一句话**，再去全仓扫；不要复用上次的 grep 字面。
2. **扫族给可复现口径 + 计数 + 谁扫的**：实测那次的 `parseInt` 族是 **21 处 / 13 键**
   （19 处在 `packages/server/src`、2 处在 `scripts/`），**三方独立重跑一致**才写进票面。
3. **扫完按键面抄录**（键名 × 处数 + 文件清单），别只写总数——只写总数，下一个人
   无法判断「整族是否真清」。
4. **派活前复核三样**：①锚点/位置是否漂移；②族边界是否漏站点；③漏掉的是否属热路径。
5. **族面数字变化要分清「漏改」与「后续主动并轨」**：同一票立项时点与收口时点的点数可以不同
   （实测 7 → 9），多出的两处若是后续票主动并轨，方向是收敛——**别把口径差记成漏改**。

## 同族：布尔开关按「默认侧」选读法

env 的另一条姊妹口径，同一类坑（**按字符串长相判，不看语义**）：

- 现场：一个开关原实现是 `=== '1'`，于是 `.env.example` 里写 `MEMORY_A2A_ENABLED=true`
  会被**静默读成「关」**。
- 改造时审查者建议照抄全仓宽松惯例 `!== 'false'`——**实核发现那条更糟**：它会让
  `.env.example` 已写明的 `=0`（关闭）**反转为启用**（`'0' !== 'false'` 为真）。
- 正解：收 **`1` / `true` 两种拼法**（`trim` + 大小写不敏感），**其余一律落默认关**（fail-closed）。
- 仓内先例逐字同款：`scripts/handoff-gen.mjs` 的 `isForceDeliver`，其注释写着「不做『非空即真』，
  否则 `CATSTUDY_FORCE_DELIVER=0` 这种手滑会静默变成『强制投递』」。
- **通则：惯例要按默认侧方向选，不能按字符串长相选。** 默认关的开关套宽松惯例 ⇒
  一行 `=0` 就能把它打开。落 `.env.example` 时同步改读法矩阵测试。
- 别与既有卡 [断 env 看回落默认值不算数](env-default-assertion-is-coincidence.md) 混引：
  那张讲的是**测试断言**钉在默认值上会假绿，与本条不同题。
