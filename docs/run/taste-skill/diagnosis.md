## 结论

**两页的骨架是健康的（语义色用法、真实数据、空/错/加载三态齐备、token 体系已成规模），
真正拦路的不是"审美不行"，而是三件可量化、可批量修的事**：

1. **浅色主题下所有主按钮的对比度是 2.52:1**（§4.5 硬门 4.5:1）——`--accent` 上放 `--bg-deep` 反色字，两页每一个 primary 按钮、active tab、徽章全中。
2. **`--text-muted` 在全部四种底色上都不达 4.5:1**（暗 2.84~~3.26、亮 2.54~~2.82），而它是这两页出现频率最高的次要文字色；设置页还有两处 `opacity: .7` 把它压到 **2.05:1**。
3. **设置页新建表单四个字段全靠 placeholder 当标签**（§4.6 "No placeholder-as-label. Ever."），且两页都没有 `::placeholder` 规则 → 占位符走浏览器 UA 默认色，在深底上对比度不可控。**"唯一标签" 同时是 "颜色不受控的标签"。**

其余均为中低severity的成规模项（`transition: all` ×17、无 `prefers-reduced-motion`、全仓零 `:active`、
评估页 24 处硬编码 hex、设置页一处冷蓝 `rgba(96,165,250)`），详见 §2。

## 4. 一句话总评

**这两页不是"AI 味重"的页面，恰恰相反——语义色、真实数据、三态齐备、z-index 留痕，
是「工程上很清醒」的界面；它的短板集中在"设计系统只做了一半"：
token 起了个头（`index.html` 两套完整变量），但被 24 处硬编码 hex 和一处冷蓝凿穿，
而最高频的 `--text-muted` 与浅色主按钮从没被算过对比度——于是最该读的文字最看不清。**
