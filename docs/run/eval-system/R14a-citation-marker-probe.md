## 二、独立变量：指示语措辞（**店长定稿，实施者不自拟**）

遵循度是**措辞的函数**——自拟一版测出的数，对定稿版零信息量。故措辞由店长给，甲/乙两版对照：

- **甲版**：`（以下为检索到的历史结论。若你采纳了其中某条，请在该处标注其编号，如 [1]；没有采纳的条目不标。）`
- **乙版**：`（采纳某条时标注其编号，如 [1]。）`

⚠️ 两版都**不作位置要求**（句末 / 词后皆可）——位置本身是待观察量，**别在指示语里加成第二个自变量**。

## 三、依赖变量：**三分判据，不许并成一个「遵循率」**

| 失效模式   | 含义                             | 修法方向                              |
| ---------- | -------------------------------- | ------------------------------------- |
| 不标       | 用了某节但一个号都没写           | 改措辞 / 加强指示                     |
| 标错号     | 标了 `[2]` 但内容其实来自第 3 节 | 改指示里对「编号↔内容」对应关系的描述 |
| 标不存在号 | 只注入 3 节却写 `[4]`            | 后端降级（R14b），**非措辞问题**      |

**并成一个比率会分不清「不会标」和「标错」——而这两者修法相反。**

## 四、探针形态（**店长裁决**）

**不新建离线调用链。** 复用现成的 adapter 工厂（`packages/server/src/llm/registry.ts`），探针只做**调用方**：

- 落点 `scripts/probes/r14a-citation-probe.e2e.mjs`（同目录已有 `dsh-acp-probe.e2e.mjs` 同范式）
- `.e2e.mjs` **不在** vitest include ⇒ 天然隔离、不进 CI
- 理由：新建一条独立调用链 = 又造一个可能与生产不一致的真相源（「离线跑通、线上不通」）；adapter 工厂是现成的，探针没有理由自建

⚠️ **注入串必须与生产同形**——形状规格（逐字取自 `renderSections`）：`【相关记忆】` 头 + 换行 + 逐行 `序号. 正文`：

```
\n\n【相关记忆】\n1. <第1节正文>\n2. <第2节正文>\n3. <第3节正文>
```

指示语插在 `【相关记忆】` 头之后、`1.` 之前。**探针不许自拟记忆段格式。**

⚠️ **`parseMarkers` 的判据面**（否则读数被假阳性污染）：

- **围栏代码块内的 `[n]` 不计入**（或至少分开计数）——猫举代码例时会写出 `[1]`
- **猫复读指示语 ≠ 标了**：甲版指示语**自身含字面量 `[1]`**，猫转述/解释该指示语时会产生 `[1]`。故判据须取「正文里指向某节内容的标注」，复述指示语那一处要能识别并剔除

## 七、问题集（实施者从 dev 库挑，判据如下）

3 个问题，每题必须满足：

- 答案**只在索引文档里**（`docs/adr` `docs/lessons` `docs/plans` 白名单切片）——答得出才可能引用
- **非 a2a**（普通用户提问）——a2a 触发时【相关记忆】整体跳过（见 `shouldSkipA2aMemory`），走不到本探针要测的那条路
- **每题必须带答案锚点 `expectSection`（1..n）**：出题时钉死「本题答案出自注入的第几节」，且该题**只有一个**承载节

**为什么 `expectSection` 是必需项（不是可选项）**：§三 三格里的「标错号」——「标了 `[2]` 但内容其实来自第 3 节」——**正则算不出来**，它要的是内容与节的对应关系。没有答案锚点，§八 验收 1 里那一格**只能编**。

出题时把「问题原文 / 本次注入的三个节原文 / `expectSection`」一并落进报告，人工可复核。

## 八、验收标准

1. 报告给出 4 provider × 三分判据的**原始计数**（含分母），非仅比率。四格归类口径**按此实施，不自拟**：
   - **标对** = 合法号集合含 `expectSection`（§七 答案锚点）
   - **标错号** = 标了合法号，但**不含** `expectSection`
   - **标不存在号** = 出现 `> 节数` 或 `< 1` 的号——**单列，不计入「标错号」**（那是 R14b 的后端降级面，不是措辞问题）
   - **不标** = 一个号都没出现
   - 四格**各自成列**；原始 `markers` 必须原样列出——混标（既有合法号又有越界号）时不得互相掩盖
2. 甲/乙两版**同条件对照**（同问题集、同 provider、同 N）
3. 不可达 provider 显式标「未测」+ 原因
4. 探针产出的注入串与 §四形状规格**逐字一致**（建议加静态源断言守卫：格式规格 `renderSections` 一变即红）
5. 结论只答「措辞能不能用 / 哪版更好」，**不预写 R14b 的接入结论**
6. **探针自身非退化**（**新增·承重**）：形状漂移必须**报错**，不许静默返回 0。判据——迭代中「见到 chunk、但无一条带可识别 `content` 字段」⇒ 单列 `shape-mismatch` 状态，**不得**并入「done 但无文本」（后者是本仓实测过的真实形态；两者混同 = 拿假读数当结论）。**仅写注释不算**——本轮已踩一次（`chunk.text` vs `Chunk.content`，四只同形假读数）
7. **原始读数落 `docs/eval/` 持久 JSON**（`--out docs/eval/r14a-citation-probe-<date>.json`）——对齐本批刚落的口径：引「实测」数必须锚**仓库内持久产物**，scratch 工作区只作过程证据
