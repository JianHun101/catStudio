1. **实现已落地**：`packages/server/src/memory/index.ts:487-517`，末次截断从按**片**切（`.slice(0, topK)`）改为按**节**计名额（节的代表 = 排序后最靠前的那片）。`:606` 的 `bySection` 及其后预算循环**未动**。

4. ⚠️ **在现制档 k=3 上，可用收益 = 0**：real 0.5833 / constructed 0.8261 与片级**逐值相等**；唯一「恢复 1/11」落在**负例 N04** 的 `expect` 锚上（N04 本就判红，`forbid` 命中数不变）⇒ 不产生任何可用增益，代价却是 +15% 注入。
5. **收益只在 k≥5 出现，且全落在 constructed 组**：k=5 constructed 0.8696 → **0.9565**（+2 条），恢复 3/11 → 5/11；real 组**五档全等**（0.5833/0.5833/0.6667/0.6667/0.6667）⇒ **real recall 对截断粒度完全不敏感**。

**K=8 那格不一致的解释**（票面验收④要求的「失真原因」）——**真跑比重建好，不是比重建差**：

- **恢复数真跑高 1 处**（6 vs 5）：T3 的重建把「取前 K 个不同节」实现为「在**重建的片级合并序**上取前 K 个不同节」，而它重建所依赖的合并序本身是**用那份 410/19 语料**算的；本次语料已长到 428/20。

- ⇒ 「重建 = 恰好 K 节」是**上界**，真跑必然 ≤ 它；「恢复数」的偏差来源是语料，**方向不定**。

**验收④「真跑若低于重建值须写明失真原因」——本文十跑里没有一跑低于重建值**（两格相等、一格高于）。

## 七、⚠️ 与票面边界的冲突（请裁决）

**票面边界明写**：「**不增注入量**（同 K 下注入节数应与现制持平或更少）」。

**实测**：同 K 下**节级恒增**，且**不可调和**——

| K   | 片级 40 条总注入节 | 节级 40 条总注入节 | 增幅       |
| --- | ------------------ | ------------------ | ---------- |
| 3   | 104                | 120                | **+15.4%** |
| 5   | 158                | 197                | **+24.7%** |
| 8   | 233                | 296                | **+27.0%** |

**为什么这是机制而非实现偏差**：片级切出的 K 个名额会被同节的重复片占用，经 `bySection` 去重后**实际节数 ≤ K**（本批 k=3 有 14 条 < 3）；节级按定义填满 `min(K, 库内可用的不同节数)` ⇒ 均值恒为 K。**「不再浪费名额」与「不增注入量」是同一件事的两面，不可能同时成立。**

**因此票面验收与边界存在一处互斥**，三条路请店长裁：

- **甲**：接受「节级 = 恒 K 节」，把边界改写成「**注入节数不超过 K**」（保留原意里真正想守的那条：不许借改动变相抬 K）。
- **乙**：放弃本改动（它唯一的硬收益在 k≥5 的 constructed 组，而现制档 k=3 上可用收益为 0）。
- **丙**：把改动与「抬 topK 到 5」**绑成一票**（节级 k=5 是本文唯一的显著收益格：constructed 0.8696→**0.9565**、恢复 3/11→5/11），代价 = 多注入 +25% 节、2 条预算截断、**多红一条负例（N03）**。

### 7.1 ✅ 店长裁决（2026-09-21，收口时落）：**取【丙】**

**逐条理由**：

- **不取【甲】单独成立**：现制档 `k=3` 上可用收益 = **0**（real / constructed 与片级逐值相等），代价却是注入 **+15.4%**、T3 诊断脚本一条承重自证被打断（§8.3）、`section_dup` 不可达、`candidateChunks` 语义漂移。等于「改了语义、断了工具、收益为零」。

**缺陷**：末次截断那轮循环原为「先 `push` 后判界」，`ordered.length >= params.topK` 永远在

⇒ 0 节 + `reason='no-hit'`；首版实现翻成 **1 节 + `reason='ok'`**（看着完全正常，实为

> ⚠️ **「与 `.slice(0, topK)` 逐字同义」这句话只有 `topK = 0` 成立，`topK < 0` 不成立**
> （我自己首版这么写，复核时纠正）：`.slice(0, -1)` 是数组**负索引**语义 ⇒ 旧行为在
> `topK=-1` 时**保留末尾 n-1 节**（3 片库 ⇒ 2 节，纯属意外）；本处一律空集 = **有意的行为
