## 一、缺口：不是「没有度量」，是「度量只跑过一次且活链是关的」

评测体系的**自指环**——判官是人工标注的替代品，判官不可信则 P3 没退路。这条判断本身**成立**，
但它指向的缺口此前被描述错了。真实结构是**两段**：

```
① 选型面（一次性）        ② 常驻面（今天不存在）
Phase 0 · 2026-08-10      ────────────────────────
50 条人工标注样本          活库判官分 × 活库人工回标
离线 CLI --collect/--run   累积、可复算的一致性分母
选 pinned judge 模型       无
```

**① 已有且已交付**（见 §二）。**② 完全空缺**，且是**双重空缺**：

- **分母端关着**：根 `.env:22` `EVAL_SAMPLE_RATE=0`。`getSampleRate()`（`sampler.ts:23-27`）在 `raw <= 0` 时返回 0
  ⇒ `maybeScoreSample`（`sampler.ts:33`）永不评分 ⇒ 活库 `eval_scores` **0 行**。
- **度量端不存在**：`agreementRate` 的**唯一非测试调用点**是 `phase0.ts:462`（离线批跑）。
  `userFeedback` 仓储（`db/repository/userFeedback.ts`）**只被回标路由消费**（`hasFeedback` / `getByEvalScoreId`），
  **全仓无一处**把 `eval_scores.score` 与 `user_feedback.user_score` 做一致性计算。

⇒ 即使把采样率打开，**也依然没有人算一致性**：回标数据会进 `user_feedback` 表然后躺在那里。
这是本票要做的**唯一一件事**。

## 三、缺口的精确形状（本票要回答的问题，不是猜测）

1. **活链要不要开**：`EVAL_SAMPLE_RATE` 从 0 起跳 ⇒ 判官开始花钱（kimi-k3 经 deepseek adapter 走 Moonshot HTTP）。
   这是**运营成本决策**（开 = 每条采样回复一次 LLM 调用），**归用户**，不归架构。**本票不预设答案**。
2. **常驻度量拿什么当分母**：`user_feedback` 是**人主动回标**产生的，与随机采样是两条独立流。
   ⇒ 一致性样本数 = 二者交集（同一 `eval_score_id` 既有判官分又有人工分）。**分母攒到多少算数**（30？50？）须钉。
3. **常驻形态选哪个**（§四 待裁）。
4. **人工是谁**：Phase 0 用的是用户本人 30 条标注。常驻面的回标若也来自用户，则**自指环只破了一半**
   ——「判官 vs 用户」的一致性测的是判官像不像用户，测不出二者共同的偏差。**是否引入第三方标注**（或至少显式声明只有用户一个标注源）须钉。

## 五、边界

- **不改**判官模型（kimi-k3 已选型定型，重选是另一票）；
- **不改**闸门阈值（0.7/80%/15pp 是九轮审查钉的契约，放宽 = 让没校准的尺子驱动决策，已被店长否决过）；
- **不改** `eval_scores` / `user_feedback` 的表结构（本票纯读；要动表走迁移台账那条链）；
- **不动** `phase0.ts` 的离线路径（它是选型工具，与常驻度量各自成立）；
- **不开**采样率（运营决策，归用户）；
- 形态甲若落地含 server 代码 ⇒ **走审查链 + 一次重启审批**。

## 六、验收标准（形态定为甲时；行为可验证）

1. 空库对照：`eval_scores` / `user_feedback` 均 0 行 ⇒ 端点返回**显式「样本不足」**而非 `NaN` 或 `null`
   （本仓已有反例：`parseFloat` NaN 族的五处 fail-silent，见 [OQ-6](OQ-6-env-threshold-nan.md)）；
2. 构造夹具：N 对已知分数（含「双方同为 pass/fail」「任一方 3 出分母」两类）⇒ `agreementRate` 读数与手算一致；
3. 分母下界：低于下界时返回 `counted` 真值 + `sufficient: false`，**不得**用不足样本给出判定；
4. 与 `phase0.ts` 同口径断言：同一组输入喂 `agreementRate` 与端点，读数**逐位相同**（防第二条真相源）；
5. `pnpm test` + `node scripts/lint.js` 全绿。

**形态定为乙时**：验收 = 重跑报告落 `docs/eval/`，且报告须写明**分母条数**与**标注源**（用户单人 or 多源）。
