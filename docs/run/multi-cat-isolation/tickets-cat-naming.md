# 票：猫 worktree / 分支命名改用中文猫名

> 归属：多猫并行隔离 —— 命名子决策（`adr-0015-draft.md` §7 第 3 点，原文标注「`cat8` 保留……唯一可无痛替换子决策」）。
> **立票 2026-09-15**（用户指令：「带中文猫名，方便观察。如果有潜在转码风险就换回 id」）。
> **前置已满足**：店长仓外实测 8 条读数（§一），**判无转码风险 ⇒ 本票执行，不换回 id**。
> **下游**：Phase I（接线）。本票**改的是生产行为**（worktree 路径 + 分支名），落地后需重启 server。

---

## 结论先行

1. 现状：`<sid8>-<cat8>`，`cat8 = agentId.slice(0, 8)`（`git-utils.ts:279-281`）—— uuid 前 8 位，**人眼认不出是谁**。
2. 目标：`<sid8>-<猫名>`，例 `f3517413-暹罗猫`。
3. git 工具链对中文**全链支持**（§一 实测），故不换回 id。
4. **真风险不在 git，在本仓代码**：`sessionShortId` 的字符过滤 `[^a-zA-Z0-9-]`（`git-utils.ts:265`）若被复用到猫名上 ⇒ 中文**整串剥成空串** ⇒ 产出空 cat8 分支 `session/<sid8>-`，失败形态**静默**（与已固化的 S3-5 同形）。红线 1 即此。

## 二、契约

### 2.1 命名规则

| 项                   | 现值                     | 新值                     |
| -------------------- | ------------------------ | ------------------------ |
| 猫分支               | `session/<sid8>-<cat8>`  | `session/<sid8>-<猫名>`  |
| 猫 worktree 目录     | `<prefix>/<sid8>-<cat8>` | `<prefix>/<sid8>-<猫名>` |
| 会话 worktree / 分支 | `session/<sid8>`（不变） | 不变                     |

`sid8` 仍走 `sessionShortId`——**会话 id 是 uuid，不受猫名影响**。

### 2.2 硬约束

1. **禁止复用 `sessionShortId` 的字符过滤正则**。猫名另立清洗：只剔除 git ref 非法字符（`/ \ 空格 ~ ^ : ? * [ " .. @{` 及控制字符、首尾 `.`），**且清洗后为空必须显式抛错**——不得静默降级为 id 或空串。
2. **唯一性**：同一 sid8 下猫名必须唯一；重名 → 显式报错，不得静默复用别人的 worktree。
3. **不保留 `cat8` fallback**：取不到猫名就报错。保留 fallback 会让"中文名没生效"再次变成静默。
4. 存量分支 `session/<sid8>-<cat8>` **不迁移**（ADR §7）；新老并存期间 `session/<sid8>-*` 通配须能同时命中两者。

## 四、红线

1. **走 worktree 模式**（在 worktree 内干活，`git -C <worktree>`；不 push、不自行合并）。
2. 提交限定路径，勿 `git add -A`（「worktree 内 add -A 已安全」已由 §一 #8 实测，但**本仓惯例未改**——见另议单；本条仍按现行惯例执行）。
3. **开工前先确认无并发实例**（`git status` + 查 `execution_logs` 同 agent 时间窗）—— 本会话刚发生过 `execute crash` 判死后原进程仍在写的形态。
4. 落地后**需重启 server 生效** → 完成后回报店长，由店长发重启审批。
