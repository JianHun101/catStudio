## 四、重启判定（取证，非断言）

改动面 `git diff --name-only 284ec3f da7415b` 实测 **18 文件**，其中 `packages/server/src/` 下
**5 个非测试生产文件**。三列判据逐列钉死（抽验员按字面复算曾与首版对不上，根因是列名与判据不同面，见下）：

- **新增行** = diff 中 `^+` 开头、排除 `+++` 头的行（**含空行**）；
- **其中非空** = 上一列再去掉 `+` 后 `trim()` 为空的；
- **其中非注释** = 再排除**去缩进后**以 `//` / `/*` / `*` 开头的。

| 文件                                                 | 新增行 | 其中非空 | 其中非注释 |
| ---------------------------------------------------- | ------ | -------- | ---------- |
| `packages/server/src/execution/serial.ts`            | 146    | 143      | **96**     |
| `packages/server/src/execution/reply.ts`             | 9      | 9        | **2**      |
| `packages/server/src/llm/session-closeout.ts`        | 113    | 107      | **59**     |
| `packages/server/src/llm/git-utils.ts`               | 143    | 136      | **76**     |
| `packages/server/src/db/repository/executionLogs.ts` | 26     | 25       | **7**      |

⇒ **有可执行的生产码改动**（不是注释、不是测试）⇒ **需重启**。

> **列名更正（抽验整改）**：首版「新增行」列装的是**非空**新增行（143/9/107/136/25），列名却写成字面的「新增行」，
> 抽验员按 `--numstat` 口径复算得 146/9/113/143/26、判为不符 —— **是列名与判据不同面，非数字造假**。
> 已拆成「新增行 / 其中非空 / 其中非注释」三列并逐列写明判据。**重启结论不受影响**：判定后腿是「非注释」列，
> 该列两版一致（96/2/59/76/7）。
>
> **判据敏感度**：非注释列若按**字面（不 trim）**口径读，得 141/9/104/131/24 —— 差异全部来自**带缩进的注释行**
> 被误计。故「非注释」一律指**去缩进后**判前缀；引用本表请连判据一起引。

> **口径自律**：本条按**改动面实测 + 行级取证**判定，不按文件名归类、也不凭交付自陈。
> 上一票（`precommit-scope`）我曾按文件名归类写下「无 server/shared 生产码」而措辞失准；
> 这一票把「含 `packages/server`」再往下追了一层——**含 server 文件 ≠ 要重启**，
> 要的是「跑着的那个进程，行为会不会变」。本票会变，且变在三处主路径上。

**本票重启后生效的行为**（三处，全部在主路径）：

1. `reply.ts` —— CLI cwd 按角色分派（store → 会话 worktree；其余 → 各猫 worktree）；
2. `serial.ts` —— 收尾块的提交 / 清理**目标树改为逐猫**（原为会话级一棵树 `git add -A`）；
