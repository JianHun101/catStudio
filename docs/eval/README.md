# docs/eval —— 跑批产物索引

本目录是**检索评估线的跑批快照**（产物，不是活文档，也**不是垃圾**）。回答三件事：哪份产物是
哪一批、由哪个脚本产出、当时回答什么问题。

## 口径（引用这些数字前先读）

- **手工快照机制**：没有自动重跑，产物是某一刻手工跑出来的。故「这份读数还能不能引」的判据
  不是日期，是报告 §一 的 `chunks 行数 / doc_path 数` 与「索引新鲜度」能不能对上**当前**库。
- **基线数字随语料过期**：同一脚本、同一黄金集，语料变了数字就变（实证：09-19 读 395 行/13 文档，
  09-20 读 410 行/19 文档）。跨批次比数字前先对语料读数。
- **报告断档**（09-20 之后无新基线）不是故障，是评估线在票序里后置——不属本目录的问题。
- 引「实测」数必须锚**本目录的持久产物**；scratch 工作区的临时读数不作数。

## ⚠️ 禁移动

`retrieval-golden.json` **同时是评估中心的仓库根哨兵**（`packages/server/src/routes/eval.ts` 的
`RETRIEVAL_REPO_MARKER`）——它缺席则报告目录解析不出来。另有多处硬编码路径引用本目录文件名。
**要挪文件先扫消费面**，别按「目录整洁」的直觉动。
